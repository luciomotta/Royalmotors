# Royalmotors

## Descrição
Minhas Past é um site que oferece cotações de veículos usando a Tabela FIPE. Ele é integrado com um iframe e uma API do Trello para fornecer cotações de veículos para a loja Royal Motors.

## Conteúdo do Projeto
- `src/img` - Pasta contendo imagens, incluindo o logo do projeto (`logo.png`).
- `static` - Diretório estático com arquivos essenciais para a interface.
- `templates` - Pasta com os templates HTML para a interface do usuário.
- `.env` - Arquivo de ambiente para configurações sensíveis.
- `README.md` - Este arquivo que fornece informações sobre o projeto.
- `app.py` - Arquivo principal contendo a lógica do backend.
- `tests.py` - Arquivo com testes para as funcionalidades do projeto.

## Instalação e Uso
### Pré-requisitos
- Python 3.x instalado.
- Configuração do ambiente virtual (recomendado).

### Passos para Instalação
1. Clone o repositório: `git clone https://github.com/seu-usuario/minhas-past.git`
2. Acesse o diretório do projeto: `cd minhas-past`
3. Instale as dependências: `pip install -r requirements.txt`
4. Configure as variáveis de ambiente no arquivo `.env`.

### Execução do Projeto
1. Inicie o servidor: `python app.py`
2. Acesse o site localmente através do navegador: `http://localhost:8000`

## Configuração do Ambiente
- As variáveis de ambiente podem ser configuradas no arquivo `.env`. Certifique-se de preencher as chaves necessárias para a integração com a API do Trello.
